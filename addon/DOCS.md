# Fast Home Control Dev

Configuration 탭 또는 웹 UI 관리자 모드에서 OpenRouter API 키(및 모델 선택)를 입력하거나 Microsoft Foundry의 API 키, HTTPS 리소스 endpoint, Decision-1 배포 이름을 입력하세요. 최소 한 공급자만 필요합니다.

웹 UI는 기본 사용자 리모컨 모드와 관리자 설정 모드로 나뉩니다. 자연어 명령으로 조명, 스위치, 에어컨/공조(climate)를 제어할 수 있습니다.

- 조명/스위치: “거실불 켜줘”, “거실 조명 빨간색으로”, “조명 조금 어둡게”, “천장등 색온도 3500K로”, “집에 있는 조명 전부 꺼줘”
- 에어컨/냉난방기: “에어컨 켜줘 송풍모드”, “거실 에어컨 25도로”, “에어컨 꺼줘”
- 동적 바로가기: 최근 성공한 명령을 원클릭 카드로 즉시 재실행할 수 있습니다.
- 관리자 모드: 공급자/모델 동적 설정, 도메인 및 엔티티별 개별 제어 범위 지정, 상세 진단 로그 확인.

HA 주소·토큰·개별 기기를 수동 입력할 필요가 없습니다. Supervisor 내부 토큰을 통해 기기를 자동 탐색하고 동기화합니다.

허용된 기기 메타데이터와 명령이 설정한 AI 공급자로 전송됩니다. 성공 표시는 HA의 명령 수락이며 물리 기기 완료 보장은 아닙니다. 모호하거나 범위 밖의 요청은 안전하게 거부됩니다.

자세한 설치·제약·검증: https://github.com/Kanu-Coffee/fast-home-control/tree/dev

이전 0.1 버전 업데이트 시 climate는 기본 OFF입니다. 관리자 모드에서 명시적으로 허용하세요. 지원 기능·값과 모델 확신도를 검증하므로 유효한 명령도 안전하게 거부될 수 있습니다. 속도는 측정하며 고정된 출시 통과 기준으로 삼지 않습니다.
